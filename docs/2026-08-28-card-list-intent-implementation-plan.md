# 卡牌列表 Intent 修正版实现计划

> **历史计划提示（2026-08-29）：** 本计划记录已完成的旧基线。后续逐牌 Intent、动态左扩卡列、Hover 预览、原版实时伤害和描述覆写请执行 [2026-08-29 实施计划](./2026-08-29-card-list-intent-ui-revision-implementation-plan.md)，不得继续实现本文的固定五槽或聚合攻击方案。

> 日期：2026-08-28  
> 依据：`docs/2026-08-28-card-list-intent-design.md` 及 2026-08-28 接口审计结论

## 1. 修正版边界

- 实现可复用的敌人卡牌、真实牌库循环、冻结手牌、复合 Intent、无交互 NCard 视图和显式测试 Encounter。
- 实现稳定 ID 快照的捕获、全量校验和显式恢复 API。
- 正常多人战斗依赖相同 Hook 时机与战斗 RNG 的确定性模拟，并保留实机验收项。
- 不使用无效的 MonsterModel `SavedProperty` 作为 Run 存档通道。
- 不宣称支持原版未提供的战斗中续档或断线重连；未来若获得完整战斗同步通道，再把快照 API 接入该通道。
- 快照出现未知或缺失状态、牌组或卡牌 ID 时，拒绝整个怪物快照，并将该怪物全部卡牌状态标记为故障。

## 2. 实现步骤

1. 新增稳定 ID、执行上下文、基础敌人卡牌、牌组注册表及测试卡定义。
2. 新增构造适配 runtime、卡牌行动状态、真实牌库循环、顺序执行、取消与故障处理。
3. 新增快照 DTO、捕获、无部分写入的恢复计划及显式恢复接口。
4. 新增怪物基类，负责状态注册、状态机重建替换、事件订阅和移除房间时清理。
5. 新增玩家方整体回合协调 Patch 与玩家方强制换招 Patch。
6. 新增复合数据 Intent、逐牌攻击聚合 Intent、资产预加载集合与安全回退。
7. 新增程序化 Godot 视图，复用固定 NCard 槽位，并在销毁时正确归还对象池。
8. 新增测试牌组、测试怪物、只可显式启动的测试 Encounter 和双语本地化。
9. 新增不依赖具体配置字面值的领域测试与 PowerShell 静态检查。
10. 完成集成审查、构建、全量测试和资源发布验证。
11. 更新 `CLAUDE.md`、`日志.txt`、`文档.txt`，并把设计文档状态更新为实际完成情况。

## 3. 测试约束

- 所有断言使用集合守恒、对象唯一性、顺序、幂等性、相对关系和 CardModel 规范变量。
- 不断言手牌容量、攻防值、牌组副本数量或 UI 参数等配置等于任何具体字面值。
- UI、多人和运行时私有场景接入保留游戏内验收，不以静态测试冒充实机结果。

## 4. 完成门槛

- 聚焦领域测试通过。
- `tests` 下全部 PowerShell 测试通过。
- `dotnet build` 通过。
- 修改本地化等 Godot 资源后执行 `dotnet publish`，并记录其结果。
- 所有新增类和方法具有 UTF-8 中文注释。
- 不覆盖或回退任务开始前已经存在的用户改动。
