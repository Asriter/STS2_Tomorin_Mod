# Oblivionis Boss 遭遇战 文档

## 需求描述
实现一个Boss+4子Boss的复合遭遇战，包含C位机制、多阶段转换、隐藏Boss。

## 敌人一览

| 敌人 | HP | 定位 | 命名空间 |
|------|-----|------|----------|
| Oblivionis | 600 | Boss，C位机制宿主 | STS2_Tomorin_Mod.Enemy |
| Doloris | 200 | 子Boss，默认C位，抽牌对策 | STS2_Tomorin_Mod.Enemy |
| Mortis | 200 | 子Boss，伤害类型对策 | STS2_Tomorin_Mod.Enemy |
| Timoris | 200 | 子Boss，单段高伤对策 | STS2_Tomorin_Mod.Enemy |
| Amoris | 200 | 子Boss，多段伤害对策 | STS2_Tomorin_Mod.Enemy |
| FullPowerOblivionis | 1000 | 隐藏Boss（独立敌人） | STS2_Tomorin_Mod.Enemy |

## 核心机制

### C位系统
- 非C位敌人获得Intangible（游戏内置Power），C位移除Intangible
- 玩家通过打出PositionZero状态卡切换C位
- C位切换时调用SetMoveImmediate切换敌人的C位/非C位行为状态（两个自循环MoveState）
- C位死亡按Doloris→Mortis→Timoris→Amoris→Oblivionis顺序自动切换

### HP削减与击杀Buff
- 每击杀一个子Boss，Oblivionis最大HP-150
- 击杀后所有玩家获得对应的永久Buff Power

### 阶段转换
| 条件 | 结果 |
|------|------|
| Boss死亡 + 0子Boss死 | 隐藏Boss（创建FullPowerOblivionis） |
| Boss死亡 + 1-3子Boss死 | 二阶段（HP+500回满） |
| 4子Boss全死 | 二阶段（HP=500回满） |

## 关键设计决策

1. C位切换不通过直接API调用，而是PositionZero卡打出后由CenterPositionManagerPower.AfterCardPlayed监听
2. 使用游戏内置IntangiblePower
3. 阶段切换通过SetMoveImmediate + 自循环MoveState实现
4. 隐藏Boss参照DoorRevivalPower模式

Oblivionis 一阶段 C 位状态机接口说明

需求：
- Oblivionis 不在 C 位时，不受队友死亡数量影响，沿用非 C 位行为。
- Oblivionis 在 C 位时，根据 Doloris/Mortis/Timoris/Amoris 已死亡数量选择 0/1/2/3 死亡状态机。
- 队友死亡时，如果 Oblivionis 当前为 C 位，立即进入对应死亡数量状态机第 1 招。

新增接口：
- Oblivionis.SetPhase1CStateByDeadAllies(int deadAllyCount, bool forceTransition = true)
  - deadAllyCount 会被限制在 0..3。
  - 用于 CenterPositionManagerPower 在切换 C 位或死亡数量变化时设置一阶段 C 位入口状态。

## 2026-06-26 Oblivionis enemy-turn revive fix

Requirement:
- Fix the case where Oblivionis dies during its own enemy-turn attack, for example from player Thorns after Mortis is killed, then remains at 0 HP and unattackable while rolling phase-2 moves.

Implementation notes:
- `Scripts/Enemy/Oblivionis.cs`: `WaitRelive` is marked `MustPerformOnceBeforeTransitioning = true`, so the revive move cannot be skipped by the next `RollMove`.
- `Scripts/Powers/EnemyPowers/OblivionisPowers/OblivionisHiddenRevivalPower.cs`: non-hidden paths clear `isHalfDead` and return before escaping sub-bosses. Hidden-boss handling remains limited to the 0-sub-boss-killed path.
- `Scripts/Powers/EnemyPowers/OblivionisPowers/CenterPositionManagerPower.cs`: normal Phase 2 transition now immediately escapes every living sub-boss before applying the Phase 2 passive and revive move. Hidden-boss handling is unchanged.

Manual reproduction:
- Kill Mortis to gain player Thorns, kill Amoris, switch Oblivionis to C position, leave Oblivionis at 1-5 HP with no block, then end turn and let Thorns kill it during its own attack. After the fix, Oblivionis should show and perform `Relive` before phase-2 attacks.
- For the normal player-kill path, kill any 1-3 sub-bosses, then kill Oblivionis directly on the player turn. The remaining living sub-bosses should escape immediately before Oblivionis finishes entering Phase 2.

Current phase-transition note:
- The current implementation does not auto-transition immediately when all 4 sub-bosses are killed. Phase 2 is entered when Oblivionis later dies; living sub-bosses escape during that transition, and after all 4 max-HP reductions the revive HP is based on current max HP + 500.

# Soyo Boss logic document

Scope:
- Implements only boss-related logic.
- Does not implement Encounter registration.
- Does not modify Act boss patch logic.

Main files:
- `Scripts/Enemy/Soyo.cs`
- `Scripts/Powers/EnemyPowers/SoyoPowers/SoyoEstrangementPower.cs`
- `Scripts/Powers/EnemyPowers/SoyoPowers/SoyoPhaseControllerPower.cs`
- `Scripts/Powers/EnemyPowers/SoyoPowers/SoyoTaskPower.cs`
- `STS2_Tomorin_Mod/localization/eng/powers.json`
- `STS2_Tomorin_Mod/localization/zhs/powers.json`

Core APIs:
- `Soyo.RefreshPhaseByEstrangement()`: called at player turn start to switch between mask and true state.
- `Soyo.StunOneTurn()`: uses built-in `CreatureCmd.Stun`.
- `SoyoEstrangementPower.GetAmount(Creature owner)`: reads Estrangement.
- `SoyoEstrangementPower.Modify(PlayerChoiceContext choiceContext, Creature owner, int delta, AbstractModel? source)`: modifies Estrangement and clamps it to minimum 0.
- `SoyoTaskPower.ApplyRandomTask(PlayerChoiceContext choiceContext, Creature owner)`: applies one random shared task.
- `SoyoTaskPower.RemoveCurrentTask(Creature owner)`: removes existing Soyo tasks.

Mask state moves:
- Gain 20 -> 25 Block, apply 2 Weak to all players.
- Attack 9 -> 10 x2.
- Heal 18 -> 23 HP, Estrangement -2, gain 1 Strength.

True state moves:
- Attack 24 -> 27 and add `min(Estrangement - 5, 4)` Wounds to each player's draw pile.
- Attack 3 -> 4 x current Estrangement.
- Each true-state move reduces Estrangement by 2.

Task rules:
- All players share a single task.
- Requirements scale by current player count.
- Attack task: play `3 * playerNum` Attack cards.
- Skill task: play `3 * playerNum` Skill cards.
- Play Cards task: play at least `4 * playerNum` cards.
- Keep Hand task: all players need at least `4 * playerNum` cards in hand in total at player turn end.
- On failure, Soyo gains Estrangement equal to the missing count.

Task rewards and penalties:
- Attack success: all players gain 3 built-in temporary Strength. Failure: all players gain 1 Weak.
- Skill success: all players gain 3 built-in temporary Dexterity. Failure: all players gain 1 Frail.
- Play Cards success: all players gain 1 built-in Energy next turn. Failure: all players lose 3 HP.
- Keep Hand success: all players draw 1 extra card next turn. Failure: all players gain 1 Vulnerable.

Easter eggs:
- First `PrideManSaki` per player: Soyo is stunned one turn and Estrangement +5.
- First `DoEverything` per player: Soyo gains 2 Weak and 2 Vulnerable.
- First `UtakotobaToken` per player: Estrangement -5.
